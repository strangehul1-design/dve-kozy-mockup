# Две Козы - макет лендинга

Одностраничный сайт гончарной мастерской «Две Козы» (Екатеринбург): мастер-классы, свидание в мастерской, романтический завтрак, творческие вечера, подарочный сертификат и форма заявки.

**Смотреть:** https://strangehul1-design.github.io/dve-kozy-mockup/

- Чистый HTML/CSS/JS в одном файле - [`dve-kozy-mockup.html`](dve-kozy-mockup.html), без сборки.
- Адаптивная вёрстка: проверена на ширинах 375 и 1280 px, горизонтальной прокрутки нет.
- Цены и тексты - из сообщества мастерской ВКонтакте (раздел «Услуги», статьи про свидание и сертификат, закреплённый пост).
- Стиль по логотипу и обложке сообщества: жёлтый круг и чёрный жирный шрифт, «полароиды» с кнопками; Dela Gothic One + Golos Text.

## Что заменить перед запуском

В коде расставлены метки - ищите по ним:

| Метка | Что это |
|---|---|
| `ФОТО` | плейсхолдеры фотографий в «полароидах» |
| `ЛОГОТИП` | знак в шапке и футере (сейчас временный жёлтый круг) |
| `ОТЗЫВЫ` | места под настоящие отзывы с Яндекс Карт или ВКонтакте |
| `TODO` | часы работы, ссылка на организацию в Яндекс Картах, политика конфиденциальности |
| `ЧЕРНОВИК` | тексты, которых нет в сообществе, - согласовать с мастерской |
| `ЗАПИСЬ` | ссылки онлайн-записи, если мастерская подключит YCLIENTS или DIKIDI |
| `FORM_CONFIG` | отправка заявок (сейчас демо-режим) |

## Запись

Кнопки «Записаться» у форматов - `.js-book` с ключом в `data-booking`. Пока ссылки в `BOOKING_LINKS` пустые, кнопка открывает форму заявки с уже выбранным форматом. Если впишете ссылку на онлайн-запись, кнопка откроет её.

## Форма заявки

Работает: выбор формата, маска телефона, проверка полей, согласие на обработку данных, защита от ботов, экран «Заявка отправлена». Сейчас заявка никуда не уходит (демо-режим). Чтобы подключить, заполните в `FORM_CONFIG.transport` один из блоков:

- `webhook.url` - свой обработчик (PHP на хостинге), токен бота хранится на сервере. Рекомендуется.
- `telegram.token` + `telegram.chatId` - напрямую в Telegram-бота из браузера (токен виден в коде страницы).
